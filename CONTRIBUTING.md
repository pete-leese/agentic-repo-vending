# Contributing

1. `make sync` then `make ci` before opening a PR.
2. Follow [`docs/conventions/`](docs/conventions/) (style, testing, PRs).
3. Do not commit secrets — see [`SECURITY.md`](SECURITY.md).
4. Prefer small PRs; for naming/workflow/approval changes, request a second review (human or Bugbot).

Agent operators: start from [`AGENTS.md`](AGENTS.md).
